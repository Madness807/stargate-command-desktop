## Glyph and dialing reference

https://stargate-sgc.fandom.com/wiki/Glyph
Milky Way gate: 39 glyphs. The selected glyph aligns under the top chevron; the ring stops, the top chevron engages, then the corresponding address chevron stays lit. The project already uses a 39-glyph ring and this sequence. Reference only; no Fandom image was downloaded or incorporated.

## User supplied visual targets (2026-10-28)

- clipboard-20261028-024053.jpg: technical blueprint; used for the thicker side profile and 6.70 m nominal outer diameter.
- clipboard-20261028-024111.webp: front illustration; used for front proportions, recessed orange triangular cores, nested chevron frames, lateral light fins, engraved glyphs and separate annular bands.

These images are visual references only and are not included as game textures. The useful opening follows the proportions of the front illustration; this is a visual reconstruction rather than a dimensionally exact reproduction of both drawings.
