# Community assets supplied by the user

The original received files remain in imports/. Model data and material maps are preserved in source GLBs; prepared .scn versions cap albedo textures at 2K and data maps at 1K. Meshes, materials and textures are shared across instances. Attribution is also shown in the game's credits.

## Alteran Transportation Rings

Author: Anquietas System
Profile: https://sketchfab.com/anquietas-sys
Source: https://sketchfab.com/3d-models/alteran-transportation-rings-c61c2f8191754de783e992affc5fef18
License: CC BY-NC 4.0 — https://creativecommons.org/licenses/by-nc/4.0/
Source and license are embedded in the supplied GLB metadata.

Integration: normalized scale and ground offset, original Transport Animation used for deployment/retraction, teleport flash synchronized to deployed rings. The cover uses its second UV set for the normal map through a custom shader, since Godot's standard glTF material cannot select separate UVs for that map.

License: CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/

Ground placement and scale adapted for individual enemies and four-model swarms. Material and texture assets retained. The duplicate upload is unchanged and not used twice.
